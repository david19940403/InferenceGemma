AMPLÍA TU CATÁLOGO

Nueva acción

Una acción conecta una intención con un script de uno de tus equipos.

01 Identifica la acción

Usa letras minúsculas, números y guiones bajos.
Incluye las palabras que usarías para pedirla en la terminal.

02 Conecta tu script

Debe coincidir con un host autorizado en tu app Android.
Para recibir un valor, usa un parámetro completo: "{url}".

03 Define las entradas

Añade los valores que necesita tu script. Las acciones sin argumentos no necesitan parámetros.

Esquema de tipo object con parámetros string, required, enum y default.
Solo scripts de confianza
CONEXIÓN AL CATÁLOGO

Configurar acceso

Introduce el token de tu Tool Store para administrar las acciones.

El token protege el catálogo. Las claves privadas SSH no se introducen en este panel.

¿Eliminar esta acción?

Se eliminará del catálogo. El script original permanecerá en su equipo.
